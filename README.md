# OrbiTutor Interactive Sims

Interactive physics simulations for the OrbiTutor workshops, hosted on GitHub Pages.

## Structure
- `index.html` — landing hub linking all sims
- `tir/` — Total Internal Reflection (Optics I)
- `superposition/` — Wave Superposition / Interference (Optics I)

## Put it live on GitHub Pages
1. Create a new repository (e.g. `orbitutor-sims`), Public.
2. Upload every file and folder here (keep the folder structure).
3. Repo → Settings → Pages → Build and deployment → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, Save.
4. Wait ~1 min. Your sims will be at:
   - Hub:            https://USERNAME.github.io/orbitutor-sims/
   - TIR:            https://USERNAME.github.io/orbitutor-sims/tir/
   - Superposition:  https://USERNAME.github.io/orbitutor-sims/superposition/
5. In Canva, hyperlink a slide element to the relevant URL.
